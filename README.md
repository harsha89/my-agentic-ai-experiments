# my-agentic-ai-experiments

Hands-on experiments with agentic AI: runnable notebooks that turn ideas about AI agents into something you can run and watch.

## Experiments

| Folder | What it explores |
|---|---|
| [loop-engineering](loop-engineering/) | Loop engineering for AI agents: an order desk agent on a SQLite database, with goals, triggers, context, a spine, tools, a checker subagent, intent and a human in the loop. Runs offline with a mock agent, or with Claude. |
